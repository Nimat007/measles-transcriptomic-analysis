# 01 — Bulk RNA-seq Analysis

## Overview
This work package investigates transcriptional changes in the bulk RNA-seq dataset used in my measles host-response thesis.

## Objective
To characterize gene-expression changes associated with the study's biological contrast and identify candidate genes and biological programs for further investigation.

## Dataset
- Dataset: GSE229685

## Code
- `01_bulk_discovery.R` — bulk transcriptomic discovery workflow.

## Analysis workflow
1. Prepare and inspect the input data.
2. Perform the planned transcriptomic discovery analysis.
3. Review the resulting gene-level and pathway-level outputs.
4. Document relevant quality checks and limitations.

## Outputs
Selected result tables and figures will be documented here after their provenance and interpretation have been checked.

## Status
Research work package. The scripts, outputs, and conclusions should be interpreted according to the documented analysis and validation status.
